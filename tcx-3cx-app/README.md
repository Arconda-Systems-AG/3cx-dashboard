# 3CX App Plugin for Grafana

The 3CX App for Grafana brings clarity and visibility to your 3CX system.  
It offers rich reporting and dashboard features directly within the 3CX IP PBX software.


Get started in minutes — no coding, no complexity.


### Key Features

- ##### Out-of-the-Box Dashboards
  Get instant insights with pre-built panels for key metrics:
  - Call volumes
  - Agent activity
  - Inbound vs. outbound traffic
  - Call statuses and durations
  - Quality and engagement analytics
  <br>

- ##### Multiple Database Support
  Connect quickly, whether you’re on the cloud or on-prem. Supported data sources include:
  - Google BigQuery
  - PostgreSQL
  - MySQL
  - Microsoft SQL Server
  <br>

- ##### Built for 3CX
  All dashboards are designed specifically for 3CX environments, ensuring compatibility and meaningful KPIs right from the start.


### Who Is This For?
- <strong>IT Admins</strong> looking for visibility into call infrastructure
- <strong>Support and Operations teams</strong> seeking actionable insights
- <strong>Managed Service Providers (MSPs)</strong> offering 3CX support at scale


## Before you begin

Make sure the <strong>Data Connector</strong> is configured in your PBX. For step-by-step instructions, see the configuration guides:
- [Connecting 3CX to Google BigQuery & Grafana](https://www.3cx.com/docs/google-bigquery-configuration/)
- [Connecting 3CX to AWS RDS PostgreSQL & Grafana](https://www.3cx.com/docs/postgresql-configuration/)
- [Connecting 3CX to MySQL & Grafana](https://www.3cx.com/docs/mysql-configuration/)
- [Connecting 3CX to Microsoft SQL Server & Grafana](https://www.3cx.com/docs/microsoft-sql-server-configuration/)
